# PDF documents

Drop PDFs here and they are picked up automatically (rebuild / dev server restart not needed in dev).

    src/documents/reports/annual-report-2025.pdf
    src/documents/policies/board-charter.pdf
    src/documents/notices/agm-notice-2025.pdf
    src/documents/catalogue/longhorn-publishers-2024-price-list.pdf

File name = the document title as shown on the site, lower-case, with `&` -> `and` and every other run of
non-letters/digits replaced by a single `-`. Until a PDF exists the link opens the live Longhorn page.
